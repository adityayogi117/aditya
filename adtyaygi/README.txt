ADTYAYGI.TECH - ONE PAGE PORTFOLIO

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka folder ini di Visual Studio Code.
3. Klik kanan index.html > Open with Live Server.
4. Pastikan internet aktif untuk memuat font Google.

ISI FILE:
- index.html: struktur dan tulisan website.
- style.css: seluruh desain, warna, ukuran, dan animasi.
- assets/tech-visual.jpg: gambar teknologi di sebelah kiri.

CARA MENGGANTI GAMBAR KIRI:
1. Siapkan gambar baru berformat JPG atau PNG.
2. Simpan di folder assets.
3. Ubah nama file pada atribut src di index.html.
   Contoh: src="assets/gambar-baru.jpg"

CARA MENGUBAH NAMA / DESKRIPSI:
Edit teks di bagian <section class="intro"> pada index.html.

CARA MENGUBAH WARNA:
Edit nilai warna pada bagian :root di awal style.css.

CATATAN:
- Orbit dan gambar bergerak otomatis menggunakan CSS.
- Tidak membutuhkan JavaScript.
- Tombol Explore My Work saat ini membuka aplikasi email (mailto); alamat contoh dapat diganti di index.html.
